# 快捷键与圈叉操作（2.3.3）

完整快捷键可在应用帮助中查看；下面说明本版最容易混淆的操作。

| 操作 | 当前行为 |
| --- | --- |
| T / P / L / S | 染色 / 涂鸦 / 自由链 / 框选；短按选工具，按住临时使用 |
| Option / 中键 | 按住预览，松开恢复；L 的 H 入口停用 |
| T/P 右拖 | 沿轨迹擦除；滚轮连续调整范围 |
| T/P 右双击第二下按住拖动 | 框选删除，一次手势一次撤销 |
| P 左单击 / 双击候选 | 真圈 / 假叉；Shift＋单击也画叉，再执行同类操作取消 |
| P Shift＋左拖 / 左双击第二下拖动 | 自由椭圆 |
| P Command＋单击 / 双击 | 选择或取消待应用的圈 / 叉，蓝色窄边显示选择 |
| P G / 起点图标 | 开始或结束追加起点；取消起点保留圈叉 |
| P Enter | 应用有效的蓝框结论；Backspace 不再应用 |
| L Enter | 分析整条链/环并预览；再次 Enter 重验应用 |
| S Enter | 分析框选并预览；再次 Enter 重验应用 |
| F11 | 主窗口填入全部单数；一次棋盘撤销恢复 |
| R / Shift＋R | 全部标注清空 / 当前工具清空；不修改题目 |

普通单击在松手时生效，200 ms 内的第二击会恢复第一击状态后执行双击。快速双击时
可能看到第一击效果短暂出现；无需等待计时器才能开始下一次普通操作。

一色组表示一个当前分支。首个标准圈叉默认成为绿色起点；同色多个起点必须同向。
多圈表示至少一个真，多叉表示全部假，不把多圈逐个自动填入。原标记颜色、绿色起点轮廓
和蓝色待应用轮廓分别表达来源、起点和选择。

同一候选的同类标记可按当前实际来源合成多色圈叉。删除来源后颜色立即更新，已选结论
在来源变化时取消选择，需要重新接纳。分支是否完备、互斥以及结论是否可信由用户判断。
Option 预览只改显示；Enter 才应用所选有效结论。应用后需撤销盘面时，切回 M 使用
Command＋Z；P 内的 Command＋Z 撤销批注操作。

若同候选同时有圈和叉，使用 Command 单击选择圈、Command 双击选择叉，两种待应用
方向互斥。同格或同行列宫的真结论冲突仍受保护；冲突提示不会被当成可信结论自动应用。
