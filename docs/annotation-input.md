# 快捷键与圈叉操作（2.3.4 源码候选）

完整快捷键可在应用帮助中查看；下面说明本版最容易混淆的操作。

| 操作 | 当前行为 |
| --- | --- |
| T / P / L / S | 染色 / 涂鸦 / 自由链 / 框选；短按选工具，按住临时使用 |
| A / B / C / D | 按下立即切换本工具色组；按住时，删除与清空只作用于本工具的对应色组（包含深浅两色） |
| Option / 中键 | 按住预览，松开恢复；L 的 H 入口停用 |
| T/P 右拖 | 沿轨迹擦除；滚轮连续调整范围 |
| T/P 右双击第二下按住拖动 | 框选删除，一次手势一次撤销 |
| P 左单击 / 双击候选 | 真圈 / 假叉；Shift＋单击也画叉，再执行同类操作取消 |
| P Shift＋左拖 / 左双击第二下拖动 | 自由椭圆 |
| P Command＋单击 / 双击 | 选择或取消待应用的圈 / 叉，蓝色窄边显示选择 |
| P G / 起点图标 | G 短按切换、按住临时录入、松开结束；双击取消本色起点，保留圈叉；鼠标点击切换 |
| P Enter | 应用有效的蓝框结论；Backspace 不再应用 |
| L Enter | 分析整条链/环并预览；再次 Enter 重验应用 |
| L 结论预览中 Shift＋Enter | 准备转录整链结论，自动切 P；选色并设置单／多起点后，再按 Enter 记录为本组普通圈叉 |
| S Enter | 分析框选并预览；再次 Enter 重验应用 |
| F11 | 主窗口填入全部单数；一次棋盘撤销恢复 |
| R / Shift＋R | 全部标注清空 / 当前工具清空；不修改题目 |

普通单击在松手时生效；200 ms 内第二下按住时保留首击效果，松手执行双击时再恢复首击前状态。快速双击时
可能看到第一击效果短暂出现；无需等待计时器才能开始下一次普通操作。

第二下按住后起拖，达到原有 4px 门槛时撤回首击并立即显示临时椭圆或拖框；正式结果
松手提交。S 拖动只显示虚线框，松手才增删正式选区；命中条件为覆盖格面积至少 50%
或包含格中心。起拖后回到起点仍按拖动处理。

P 轨迹擦除和矩形擦除期间，待删除笔迹保持半透明，保留部分正常显示；松手才真正删除。
工具栏“范围／整笔”图标同时控制轨迹与矩形擦除，启动时默认“范围”。范围策略局部擦除
普通笔迹；整笔策略删除命中的连续笔迹，已经局部擦开后的各段分别处理。标准圈叉仍整枚
擦除；共享多色标记按原来源范围擦除，其他来源仍保留。一次手势一次撤销，Esc 取消未提交预览。

按住 A–D 后执行右键擦除、双击拖框、Ctrl 删除或 R/Shift+R，只删除当前工具的该色组。
P 的 A 组删除不会影响 L 的 A 组。删除手势开始时固定范围，拖动中松开色组键仍按原范围
完成本次操作；下一次删除恢复普通范围。自动重复按键不重复切色，也不会打断双击。
切换工具或窗口失焦会结束过滤；短按切色无需等待长按计时器。

一色组表示一个当前分支。首个标准圈叉默认成为绿色起点；同色多个起点必须同向。
多圈表示至少一个真，多叉表示全部假，不把多圈逐个自动填入。原标记颜色、绿色起点轮廓
和蓝色待应用轮廓分别表达来源、起点和选择。

M/T/P/L/S 常态保留完整来源色，不按当前工具或色组额外淡化其他批注。当前 P 色组独有叉
只按真假语义淡化对应候选数字，叉主体仍保留来源色；共享叉不淡化数字。原生步骤显示时
先前标注的时间层淡化独立生效，后画标注保持清晰。S 非当前组仍保留完整虚线边界。

同一候选的同类标记可按当前实际来源合成多色圈叉。删除来源后颜色立即更新，已选结论
在来源变化时取消选择，需要重新接纳。分支是否完备、互斥以及结论是否可信由用户判断。
Option 预览只改显示；Enter 才应用所选有效结论。应用后需撤销盘面时，切回 M 使用
Command＋Z；P 内的 Command＋Z 撤销批注操作。

链结论转录由用户确认起点足以使已画链的额外关系成立，不表示工具复核了该前提。
准备期间选色、设置起点和普通 P 编辑不会自动转录；最终 Enter 保留本色起点，替换本色其余
圈叉／自由笔迹／椭圆，记录全部正式单候选结论，并移除来源链。真实盘面不变；冲突保留为反证素材。
切离 P、切到其他应用或原盘／来源链失效时取消准备，保留已画 P 内容及未消费原链。
Esc 先结束 G 录入或局部交互，再取消准备。主窗内选色和工具栏焦点变化不取消。
成功后 P 撤销一次恢复该次转录前的 P 内容；切到 L 撤销才能恢复来源链。撤销、重开不会复活准备状态。
出现反证或共同结论时，另一次明确 Enter 才按原 P 规则应用到真实盘面，持续按住 Enter 不连续应用。

若同候选同时有圈和叉，使用 Command 单击选择圈、Command 双击选择叉，两种待应用
方向互斥。同格或同行列宫的真结论冲突仍受保护；冲突提示不会被当成可信结论自动应用。
