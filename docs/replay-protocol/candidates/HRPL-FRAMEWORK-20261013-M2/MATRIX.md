It has 3 frames and a 65538-byte Unicode phaseLabel; it is synthetic codec input, not claimed as application export. The 16 MiB boundaries are exercised in test code rather than embedded as oversized transfer attachments.

Application validation totals are 46 headless / 54 GUI. The two actual-window images were produced by painting displayed Swing windows; the capture probe additionally checked its displayed native window with Robot. The 480/810 LIGHT/DARK board images are offscreen board renders within those tests. Neither source-built GUI evidence nor those images establish physical mouse testing or installed-package acceptance.

Windows must report its complete application matrix and return files together through WINDOWS-ADAPTATION.md. Receiving the package, checking its hashes or repeating the prototype tests does not complete that task. A successful PNG decode alone does not prove faithful display. The shared PR supports direct agent exchange but does not automatically resume an idle agent.
