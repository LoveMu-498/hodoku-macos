# 2.3.4 源码候选：保存效率与标注界面

准备日期：2026-10-10。基于公开 main 的 2.3.3，版本来源为 `src/version.properties`。
这是供云端开发和 PR 审阅的源码迭代；正式安装包、tag 和 Release 须另行验收并获授权。

## 保存与关闭

- 会话静置至少 5 秒后捕获完整快照，后台尝试至少间隔 30 秒；设置连续操作合并 1 秒，
  后台实际提交至少间隔 5 秒。明确确认设置或退出时立即提交最新状态。
- 会话、设置和回放分别串行写入；旧快照有序号保护。内容未变且磁盘 SHA-256 与已验证
  字节一致时跳过重复编码，不能只凭大小或修改时间认定文件未变。
- 完整笔迹坐标与历史使用共享几何及紧凑数组编码，保持原始 double 位、撤销/重做和存档点。
  新文件仍完整解码校验；有效旧文件与原子备份保留，未通过校验的写入不替换成功文件。
- 主动保存和退出显示进度；各独立部分尽量完成，失败显示已完成部分和目标。退出支持
  重试、取消或明确仍然退出，取消后可继续编辑。后台失败不冒充成功。
- 本次审查修复：异常重启时，同一回放身份、相同帧数且完整盘面一致的已提交本机会话，
  不再被旧回放覆盖。保留批注、历史、完整存档点并补齐后来落盘的回放书签，以及可证明的较大用时；回放更多帧、
  盘面冲突或身份不同时仍按回放恢复。仅批注或计时的恢复不制造解题操作帧。

测量方法、样本和限制见 [保存性能分析](../save-performance.md)；复现工具见
[保存数据采集](../save-telemetry.md)。重笔迹场景已有明显改善，但不能据此声称所有退出
都瞬间完成或范围擦除已经提速。

## UI 与批注

- M/T/P/L/S 常态标注保持完整可见，不再因工具或色组改变额外淡化非当前来源。
  当前 P 色组独有叉仍按原语义淡化对应候选数字；原生提示的前后标注时间层分别生效。
- 候选字形偏移按字体、尺寸和绘制上下文缓存，圈叉与数字中心保持一致；L 提示字形
  使用基础字号的 90%，不额外强制加粗。叉的主体、绿色起点轮廓与蓝色待应用轮廓更易区分。
- S 非当前组保留完整虚线边界，当前 S 组实线；重叠边呈现真实多来源颜色，保持候选核心可读。
- P 轨迹和矩形擦除可选“范围／整笔”，默认范围。松手提交、一次撤销恢复，Esc 取消；
  整笔针对当前连续笔迹，已经局部擦开后的各段独立处理。
- L 的 Shift+Enter 可将正式整链结论准备转录至 P；最终 Enter 明确确认，盘面不自动改变。
  P 与 L 独立撤销；起点、反证、共同结论与失效检查仍保留各自条件。
- 回放列表与只读查看器进一步整理入口、播放和状态提示；长解说采用有界原生扩展，
  不静默截断。跨平台显示或再次保存的能力以格式说明及对方实际验收为准。

## 升级、备份与降级

首次使用前正常退出旧版，保留旧版应用，并将整个 HoDoKu 数据目录复制到目录之外。
macOS 默认位置为 `~/Library/Application Support/HoDoKu`。升级前的外部备份必须保留；
日常 `.bak` 会随着后续保存轮换，不能代替降级备份。换应用名称不会隔离共享数据目录。

| 数据 | 本候选行为 | 2.3.3 的限制 |
| --- | --- | --- |
| 本机 `last-session.xml` | 写 v2，读 v1/v2；完整保存工作状态 | 不能恢复新版 v2；降级需恢复升级前备份或使用隔离数据目录 |
| Mac 回放原生尾 | 通常 HMX5，长文本 HMX6；读 HMX1–6 | 仅读 HMX1–3，不支持新版原生尾 |
| HRPL 公共前缀 | 保持 v3 | 前缀可读不等于保留全部新 Mac 证据及长文本；其他平台另存可能丢弃尾 |
| 已识别的旧 Mac envelope v4 托管记录 | 沿用 2.3.3 已有启动清理规则，未扩大范围 | 新版没有将 2.3.3 的 HRPL3 回放列入清理 |

旧规则只处理 UUID 命名且明确识别出的托管旧 Mac envelope v4 及其关联 checkpoint；
不将用户导出文件、外国格式、符号链接或普通题目/配置视为同类清理对象。
这是外层旧 envelope v4 的退役，与上述 HMX 尾的版本编号是不同概念。
