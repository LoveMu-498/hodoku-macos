# HoDoKu macOS 2.3.3

发布日期：2026-09-30。基于公开版本 2.3.2 推进，主应用继续使用 GPL-3.0-or-later，
保留原作者及各组件的版权、许可和无担保声明。

## 快捷键与工具操作统一

- T / P / L / S 对应染色、涂鸦、自由链和框选。普通单击立即反馈；200 ms 内第二击先恢复
  第一击状态，再执行双击动作，避免留下多余标注或撤销记录。重叠链组选器和分析中的保护仍保留。
- Option / 中键统一为按住预览，释放、Esc、失焦或换工具退出。画链旧 H 预览入口停用。
- T/P 右拖轨迹擦除，右键双击第二下按住拖动框选删除；擦除期间滚轮连续调整橡皮尺寸，
  工具栏同步显示直径。普通滚轮切换色组，Command＋滚轮调整画笔。
- F11 在主窗口不同工具和焦点下统一填入全部单数；对话框和只读回放保留输入保护。
  帮助页及工具提示同步当前操作。详见[快捷键与圈叉指南](../annotation-input.md)。

## 圈叉、起点与多色结论

- P 单击候选画真圈，双击或 Shift＋单击画假叉；再次执行同类操作取消。Command 单击选择圈，
  Command 双击选择叉；同候选圈叉共存时也能分别选择，圈叉本身保留。
- 首个标准圈叉默认起点，G / 工具栏追加或取消起点。绿色贴边轮廓、蓝色待应用选择和实际
  来源颜色分别显示。同色多起点必须同向：多圈为至少一个真，多叉为全体假；异向追加拒绝。
- 当前批注按实际来源实时合成多色圈叉，去掉一色立即更新，来源改变取消对应待应用选择。
  是否满足分支完备、互斥及可接纳条件由用户判断；人工标记不自动成为求解器证明。
- **待应用圈叉结论改用 Enter，Backspace 不再应用。** 预览不改变实际盘面；有效结论应用
  沿用棋盘事务与撤销。未选择、无变化、修饰键或只读状态不应误应用。
- 当前色组预览突出圈的数字、隐藏有效叉对应候选；矛盾显示鲜红提示。多圈起点的“至少一个真”
  不会被当成每个成员都真来填数。

## 其他修复

- 画链右键退回后恢复剩余链尾，可继续原链；闭环首次退回只断开闭合边。来源变化退出旧预览，
  Esc 取消预览时保留已完成标注。
- 单格框选可精确匹配 Full House、显性单数和隐性单数；第一次 Enter 预览，再次 Enter 重验应用。
- Tab 原生路径匹配检查完整节点、分组、强弱与拓扑；筛选区统一分组，完成数字淡显并加勾。

## 升级前：旧回放不兼容

本版使用 HRPL v3 共同格式及可忽略的 Mac 扩展。**2.3.2 的旧 Mac 回放不迁移；首次启动会
清理识别出的 UUID 命名应用托管旧回放及其关联恢复检查点。** 升级前正常退出旧版，保留旧版应用，
并把需要保留的旧回放复制到应用数据目录之外；旧文件继续使用旧版查看。其他另存文件、软链接、
个人设置及题目文件不属于该清理范围。

Mac 扩展保存完整证明、保存点、派生来源和精确标注；只支持共同格式的程序另存时可能丢失扩展。
跨窗口的像素涂鸦对齐不保证。详见[回放与分享](../replay-sharing.md)和[格式说明](../replay-file-format.md)。

## 发行与验证边界

Release 提供 DMG、与发行提交一致的应用源码、匹配 Temurin 的对应源码/构建材料和 SHA-256。
公开副本排除私人 Git 历史、内部参考、真实回放、配置、诊断日志、密钥和本机账户归档元数据。
具体本轮检查结果随 Release 记录；不把旧测试包的结果作为本版通过证据。

目标为 Apple Silicon，最低系统声明 macOS 11；尚未 Developer ID 签名或 Apple 公证。
既往 Java AWT/AppKit 原生初始化或无障碍自动化异常的根因尚未确认，不列为已修复。
事件、Robot 与渲染检查不等于全部硬件/触控板手感实测。系统分享只验证面板和取消，
不向真实联系人发送；回放中的名称、时间与题目内容仍需用户在分享前检查。
