# HoDoKu macOS 2.3.2

发布日期：2026-09-20。基于公开版本 `v2.3.1` 向前推进；主程序继续使用 GPL-3.0-or-later，
原作者及第三方许可保持不变。版本唯一来源为 `src/version.properties`。

## 本版亮点

- **解题过程可回看**：有效计时、操作时间轴、连续播放和保存点，保留盘面及相关历史证明。
  同窗只读复盘不修改当前作答，也可从选中帧开始新的解题。
- **回放可带走**：自包含 `.hrep` 导入导出与 macOS 系统分享入口，不要求接收者拥有原记录目录。
  导出正在进行的记录不结束当前解题；本地文件导出始终保留。
- **画链更清楚**：出发节点静态外圈、完整组续接及 Option 新链起点提示；全部链段统一分析，
  不连通时提供数量与参考位置。扩组引用同步且可撤销。
- **链文字可交流**：完整候选盘面和显式 Eureka 链文字互转，支持多链和可表达的 ALS 前提。
  不匹配盘面的导入需要再次明确粘贴，不静默覆盖当前作答；不宣称支持所有外部链记法。
- **标注交互改进**：条件预览保留原链配色、突出结论，滚轮累积与空闲解锁减少连续过冲。

操作和隐私注意见 [回放与分享指南](../replay-sharing.md)。

## Bug 修复与范围

回放是 2.3.2 新增功能，下列回放修复针对本轮开发阶段，不表示 2.3.1 曾包含这些回放入口。

| 问题 | 处理结果 | 保留的边界 |
| --- | --- | --- |
| 回放文件弹窗被误判为锁定的主窗口，按钮与键盘无响应 | 按事件来源自身窗口判断，恢复取消、保存、打开和目录操作 | 主作答区域的只读保护保留 |
| 回放覆盖层拦截原生鼠标事件 | 恢复回放按钮点击及正确事件路由 | 不开放底层作答修改 |
| 播放进度与提示交互不清楚 | 连续进度、当前/总用时；复用原生提示及临时坐标引用 | 回放不重新执行求解器 |
| 框链预览淡化范围与结论识别不清楚 | 原链保色、结论突出，无关旧标注淡化 | 条件关系仍显式提醒，普通 F12 路径保留 |
| 触控板连续事件造成多档变化 | 累积阈值与空闲解锁，笔宽增加四档按钮 | 合成事件验证不等于每种触控板手感实测 |

同数字组扩展为同一行、列或宫的二至三成员；跨数字强关系复用原生 ALS 前提与重验，
不把强关系误当互斥，不改变自动搜索偏好。

## 稳定推进与发行材料

发行从独立公开副本的确定提交构建；应用版本、包信息和 DMG 文件名一致。
Release 同时提供 DMG、对应 HoDoKu 源码、独立 Temurin 对应源码/构建材料和 SHA-256。
源码与附件排除实际回放、个人配置、内部记录、凭据和旧私人 Git 历史；源码归档也去除本机账户元数据。
后续上传、合并及版本推进仍需用户明确要求，不自动发布。

## 验证与已知边界

发行验证覆盖源码/打包与隐私检查、回放核心与恢复/留存、文件互通与只读交互、链/涂鸦回归，
以及成品原生依赖、签名、DMG 完整性、搬移后的实际启动/退出保存/重启。具体本轮通过数量
和运行范围随 Release 验证结果记录，不以旧日志替代当前检查。

- 当前目标为 Apple Silicon；最低系统声明为 macOS 11，验证机为 M3 Pro/macOS 27.0，
  未声称覆盖 M1 或所有旧系统。应用为 ad-hoc 签名，尚未 Apple 公证。
- 此前在 macOS 27 的 GUI 自动化中发生过一次 Java AWT 无障碍原生层崩溃，后续同包复测
  未再发生；根因未确认，不能将其列为已修复。若遇到类似退出，请保留本地崩溃报告，
  分享报告前去除私人路径和信息。
- 休眠接入与计时逻辑有测试，未通过实际让用户电脑睡眠来验证。
- 系统分享验证以面板、取消与本地导出为界，不向真实联系人发送文件；服务可用性依系统环境。
- `.hrep` 中的保存点名称和时间等是用户分享内容，导出不是自动匿名化工具。
