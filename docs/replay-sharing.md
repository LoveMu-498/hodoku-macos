# 解题回放与分享

## 看一段解题过程

通过题目菜单进入当前回放；“文件 → 回放记录…”可查看历史，“文件 → 打开回放…”可打开外部 `.hrep`。观看回放时，文件菜单中的这两个入口仍可使用。
回放记录窗口也提供“打开回放…”；取消选择文件会保留列表和当前选中项。双击记录观看，双击最右侧钉住列可钉住／取消钉住，空心与实心钉子表示状态。取消钉住沿用原有确认提示：普通记录超过上限时，旧记录可能立即被清理。
播放器的实心三角形及“播放／暂停”文字控制连续播放；单箭头切换一帧，双箭头跳转一次操作，箭头加竖线定位首尾。
回放在同一窗口只读展示，通过时间轴定位、
连续播放和保存点回看过程；观看不会把历史步骤直接应用到当前作答。
从指定帧开始解题会创建新的解题记录，保留该帧起始盘面/标注信息，不要求原文件继续存在。
外来回放的历史圈叉、描边和证明高亮留在回放中观看，不成为新棋盘按 Enter 执行的结论；已支持的框／链几何和普通用户染色继续按现有规则恢复。

记录保存盘面操作、有效时间，以及正式技巧或手画框链的相关证明。
它不是屏幕录像：不记录独立的鼠标移动、选格、画框或涂鸦动作；实际填数、删数等盘面操作附带当时的框、链、染色和涂鸦快照。
查看历史证明不表示系统重新认证了当时的每条结论；实际发生的错误变化也可能出现在记录中。

## 导出、打开与系统分享

在回放工具栏导出 `.hrep`，或通过系统分享入口交给可用的 macOS 分享服务。
系统服务不可用或操作失败时，仍可导出文件后手动分享。只有用户选择发送服务并完成操作
才会发送；打开面板本身不等于发送成功。应用不会代替用户选择联系人。
接收者可在支持该格式的版本中打开 `.hrep`，只读复盘；导入不覆盖当前作答。
新版 Windows V3 的候选真圈、假叉和结论描边可按候选位置显示。MT 共同结论开关会保留，播放器只显示文件已经记录的结果，不重新推算；缺少结果或来源时会提示。自由涂鸦的坐标参照仍须对方明确。

“导出 Windows V3 副本…”为支持新版圈叉的 Windows 提供交流文件。它保留完整 Mac 数据，补充可准确表达的基础圈叉；原生完整导出与系统分享入口保持原样。对方另存后仍可能丢失完整证明、保存点、来源帧和精确自由涂鸦，应保留完整原件。旧 Windows 读者会误读新圈叉，不能使用该副本宣称兼容所有 V3；新版 Windows 的真实显示、另存及编辑往返仍待对方验收。
本版采用 HRPL v3 共同格式及 Mac 扩展。升级前请正常退出旧版，保留旧版应用，把需要的旧回放复制到应用数据目录之外。旧 Mac envelope v4 已淘汰，不迁移；启动仅清理 UUID 命名且明确识别出的托管旧 v4 及其关联 checkpoint，本次不扩大该规则，不清理 2.3.3 的 HRPL3 记录。手动导出到其他目录的文件不自动删除。

框选解题的回放保留原始框选输入、推理结果及已应用盘面。原始框选、推理结果与已应用三帧都显示已保存原生技巧的完整候选标记，包括绿色依据、蓝色鳍与红色删除结论；关闭普通候选显示时，步骤涉及的候选仍可见。已删除的红色候选是只读历史证据，盘面保持删除后的真实状态；实际填入的数字另有高亮。从此处重新解题不会恢复已删候选或继承可执行的历史技巧。已有文件中的原生证明也按此规则显示。

圈叉应用的回放分为依据帧与结果帧。结果帧保留应用前圈叉、红色矛盾见证和蓝色结论框用于只读复盘，即使目标候选已删除也可看见。解说列出起点假设、本组手绘标记、具体矛盾及最后实际填入／删除项；自动连带候选变化另列。OR 起点仍表示“至少一个为真”，接纳不会把成员分别填入。旧回放能恢复已有圈叉，但不会凭空补造缺失的操作类型。

普通单色反证称“假设反证（手绘推导）”，按格／行／列／宫描述矛盾；致命矩形列为“唯一性反证”。分类依据 [HoDoKu 官方强制链／网的矛盾说明](https://hodoku.sourceforge.net/en/tech_last.php) 与 [唯一性说明](https://hodoku.sourceforge.net/en/tech_ur.php)，手绘来源不等于自动验证过完整链的每条连接。

Windows 另存会丢失 Mac 完整证明、存档点、派生来源、结构化圈叉步骤及精确自由涂鸦扩展；共同盘面、完整操作解说和标准圈叉候选坐标保留。标准圈叉返回 Mac 后可准确定位。明确鳍角色随公共标签保留，返回 Mac 后按原生鳍配色显示；不凭颜色重建丢失的完整技巧证明。框选、链和候选位置可随棋盘缩放，颜色依接收端配色。Windows 自由涂鸦缺少原画布信息；无法可靠定位时隐藏并提示，原始数据仍保留。Mac 导出的像素涂鸦也不能保证在不同大小的 Windows 窗口中对齐。

`.hrep` 自带所需盘面和历史证明，不需要发送个人配置、整个数据目录或原始诊断日志。
对正在进行的解题导出时，只取完整已记录前缀，不会替你结束当前解题。

## 分享前检查内容

导出排除详细恢复错误、诊断路径、日志与本地留存标记。但是操作、时间标签、题目盘面、
保存点名称等是回放内容的一部分；自定义名称可能含私人信息，不会自动匿名化。
发送前确认这些内容适合分享。不要把真实个人回放、设置或恢复检查点提交到源码仓库。

未知版本、过大/损坏文件和不完整证据会明确拒绝，不能仅凭扩展名判断可信。
文件规格及限制见 [格式说明](replay-file-format.md)。

2.3.4 的工作会话 v2 和 HMX5/6 原生尾不支持由 2.3.3 完整读取；升级前备份整个数据目录，降级按 [版本说明](releases/2.3.4.md) 使用升级前备份或隔离目录。
