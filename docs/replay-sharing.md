# 解题回放与分享

## 看一段解题过程

通过题目菜单进入当前回放或回放记录。回放在同一窗口只读展示，通过时间轴定位、
连续播放和保存点回看过程；观看不会把历史步骤直接应用到当前作答。
从指定帧开始解题会创建新的解题记录，保留该帧起始盘面/标注信息，不要求原文件继续存在。

记录保存盘面操作、有效时间，以及正式技巧或手画框链的相关证明。
它不是屏幕录像：不记录独立的鼠标移动、选格、画框或涂鸦动作；实际填数、删数等盘面操作附带当时的框、链、染色和涂鸦快照。
查看历史证明不表示系统重新认证了当时的每条结论；实际发生的错误变化也可能出现在记录中。

## 导出、打开与系统分享

在回放工具栏导出 `.hrep`，或通过系统分享入口交给可用的 macOS 分享服务。
系统服务不可用或操作失败时，仍可导出文件后手动分享。只有用户选择发送服务并完成操作
才会发送；打开面板本身不等于发送成功。应用不会代替用户选择联系人。
接收者可在支持该格式的版本中打开 `.hrep`，只读复盘；导入不覆盖当前作答。
本版采用 HRPL v3 共同格式及 Mac 扩展。升级前请正常退出旧版，保留旧版应用，把需要的旧回放复制到应用数据目录之外。旧 Mac 回放格式已淘汰，不迁移；新版本启动时清理识别出的应用托管旧记录与关联恢复检查点。手动导出到其他目录的文件不自动删除。

Windows 另存会丢失 Mac 完整证明、存档点、派生来源及精确涂鸦扩展；共同盘面与标注文本保留。框选、链和候选位置可随棋盘缩放，颜色依接收端配色。Windows 自由涂鸦缺少原画布信息；无法可靠定位时隐藏并提示，原始数据仍保留。Mac 导出的像素涂鸦也不能保证在不同大小的 Windows 窗口中对齐。

`.hrep` 自带所需盘面和历史证明，不需要发送个人配置、整个数据目录或原始诊断日志。
对正在进行的解题导出时，只取完整已记录前缀，不会替你结束当前解题。

## 分享前检查内容

导出排除详细恢复错误、诊断路径、日志与本地留存标记。但是操作、时间标签、题目盘面、
保存点名称等是回放内容的一部分；自定义名称可能含私人信息，不会自动匿名化。
发送前确认这些内容适合分享。不要把真实个人回放、设置或恢复检查点提交到源码仓库。

未知版本、过大/损坏文件和不完整证据会明确拒绝，不能仅凭扩展名判断可信。
文件规格及限制见 [格式说明](replay-file-format.md)。
