# T/P/L/S 实现参考功能清单 v4

当前唯一默认为 B2 手势：T/P 右拖轨迹擦，右双击第二下拖框；轨迹擦除时显示虚线范围圈，滚轮调整半径。按住 A–D 时，删除和清空限定为当前工具的该色组。下文包含 A/B 与后续决策历史；当前手势以文末最新日期条目为准。

此文记录 T/P/L/S 输入映射与后续演进；当前发行边界见 [2.3.4 源码候选](releases/2.3.4.md)。日期：2026-10-10。

本清单是当前完整参考入口，包含主要操作、共用语义、保留能力和验收边界。仅限 T/P/L/S；M 与回放不在本轮修改/功能验证范围。本轮用户已明确授权完整实施；以复用原能力和修改输入映射为原则。未重新实现预览、链剪裁、绘制或撤销系统。

## 本轮明确决定

1. T 最近清除统一按时间：在棋盘外画布留白右单击，格色与候选色混排从新到旧清；无分类型双击命令、无当前色组过滤。候选 A→格 B→格 C→候选 D，清除 D→C→B→A。
2. P 采用 B：普通右拖矩形擦；点自由橡皮后左键连续擦；点画笔返回。不采用双击按住第二下拖框。
3. L 右单击在整个棋盘/画布退上一连接，包括候选命中；候选右双击专属精确两端删边，右拖专属框删，不能先产生单击退尾副作用。
4. L 右框继续删画链高亮/节点或组成员与边；精确删边若使受影响候选无关联边，同步清其 L 高亮/选中，不影响数独候选或其他工具。
5. S 不提供清本色组；保留本工具全部组清空与 R 全部批注清空。
6. TPLS 的 Option 和中键专留按住预览，松开恢复；原 Option 编辑用途迁移。L 直接复用已实现的 H 邻接预览，H 作为兼容入口保留；预览时仍可按既有关系检查继续画链。
7. R 对受影响 T/P/L/S 各记一次清除，之后按当前工具独立撤销/重做；macOS 沿用 Command+Z。

## 必须同时保留的状态/事务

- 真实数独候选、T 候选染色、P 圈叉、L 节点高亮是不同对象。删除 L 高亮不得变成候选消除或清其他工具。
- L 受影响端点的最后边清理与删边是同一次撤销；不清无关独立起点。有其他保留关系的候选不丢高亮。
- L 第二端点选择拥有单击事件；选 B 不额外退尾。取消、歧义、失效目标不修改；切工具/失焦清临时选择。
- 双击专用目标的首次单击延迟提交；拖动越过阈值取消待单击；视觉提示可即时显示，数据/历史不可先写后掩盖。
- T 留白不再有特殊双击，可快速点两次清两项。L 非候选位置也无右双击入口；但同候选快速连点达到双击条件会转精确选端，这一点必须写入帮助。
- P 自由橡皮子工具保持可见；中键/Option 都不用于锁存橡皮。矩形擦每次松手一次事务。
- Option／中键按住预览，最后一个释放恢复；失焦、换工具、Esc 清临时预览。P 保留既有思路显示预览（Space 兼容），不编辑；L 保留 H 的关系约束续画。T/S 仅保留预览输入位并阻止误编辑，不新增无既有能力支撑的预览。
- 已有 P 结论外框、圈叉冲突记录、结论应用和原批注事务仍保留；不因此新增 M 或回放验证范围。

## 实现说明

- 单击存在双击含义时，仅在目标具有双击动作时使用不超过 200 毫秒的判定窗口，从第一次按下计时；无双击动作的位置松手即执行；第二次点不同目标则先完成前一次，拖动则接管而不先编辑。
- 染色时间顺序是会话内对象顺序，放在既有染色快照中；跨历史记录上限仍保留当前对象顺序。保存文件的未知过去时间不虚构。
- 功能实现与自动化输入验证不等于已经替换用户安装的应用。

## A/B 删除手势验证版

共同改动：去掉点击位置的虚线圈；有双击含义的目标判定窗口最多 200 ms，从第一次按下计时；T/P/L/S 删除矩形均有主、副两条对角线。

- A：T 右键直接拖动为矩形删除，其他既有映射保持。
- B：仅 T 右键直接拖动改为连续轨迹擦除；双击右键并按住第二下拖动为矩形删除。Control+左拖仍是矩形删除。L/S 与 A 完全相同。P 后续按用户反馈同步采用右拖轨迹擦／右双击第二下拖框，并隐藏工具栏及侧栏自由橡皮切换。
- B 复用 P 圆头扫掠几何和 T 的格中心/候选中心命中、删除范围及撤销函数。路径结束时统一提交，一个手势一次撤销；Esc/失焦/换工具取消未提交轨迹。
- B 右键任意起点均先判定，防止第一下提前清除本地或最近染色；不拖动的右双击候选仍清候选色，留白双击仍按两次最近清除处理。
- A/B 共用同一份程序，只由 B 包的启动参数启用试验手势，不保存为用户设置。

### B 涂鸦修正

先前 B 只对 T 接入试验手势，P 仍使用工具栏子工具，未覆盖用户实际要比较的涂鸦场景。当前 B 的 P 已改为普通右拖圆形连续轨迹擦除、右双击第二下按住拖动矩形擦除；无需先切换任何工具栏状态。A 不变。原生 Robot 已验证这两条 P 路径。

## 当前正式默认（取代以上 A/B 历史试验说明）

用户最终采用 B2，取消 A/B 运行分支及启动参数。T/P 均右拖轨迹擦除，右键双击第二下按住拖动框选删除；L/S 保持原映射。仅轨迹擦除期间绘制鼠标处的虚线圆形范围，普通点击不画圆；此时普通滚轮调整橡皮半径，沿用已有大小上限/下限和滚轮节流，不换色。松手/取消后不再显示范围圈，普通滚轮恢复色组切换。矩形删除均有两条对角线。原测试包作为历史文件保留，不再构建或提供 A 逻辑。

## 涂鸦显示与反馈修订（当前）

- 双击判定恢复 200 ms。P 单击松手立即显示待提交圈；数据仍按原仲裁提交，双击改为叉，不额外保存圈、不新增多余撤销记录。该即时显示仅针对涂鸦图案，不声称 T/L 也改成即时提交。
- P 右键按住时，工具栏从画笔笔宽切换到橡皮直径；滚轮调整大小并同步显示，释放/Esc/取消恢复画笔。
- Option/中键（Space 兼容）直接预览当前色组，不要求指向圈，也不随悬停别组改变；仅有叉/空组可进入并恢复。
- P 标准叉相对圈的几何尺度降至 0.62；当前组叉和对应候选用 0.45 不透明度显示。预览中叉与候选仍可见，不实际删除候选。原大圈、冲突红提示与结论外框/应用语义保留；M/回放原叉缩放不变。
