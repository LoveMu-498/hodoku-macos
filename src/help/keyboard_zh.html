平台按键说明：平台对应为 Windows Ctrl → Mac Command、Alt → Option、Win → Control。Mac Control 不再兼容 Command，专用于下述删除手势。

基本操作

使用鼠标（默认模式）
单击一个单元格可将其选中。按住 [Ctrl] 或 [Shift] 再单击，可选择一片单元格。设置单元格或候选数（Candidate）的方法：
  • 双击候选数，可将其填入单元格。
  • 如果单元格只剩一个候选数，双击该单元格即可填入此数。
  • 启用筛选器（Filter）后，如果筛选出的候选数构成隐性单值（Hidden Single），双击对应单元格即可填入此数。
  • 按住 [Ctrl] 双击候选数，可切换该候选数的启用状态。
使用鼠标（替代模式）
区域选择方式与上文相同。设置单元格或候选数的方法：
  • 左键单击候选数，可将其填入单元格。
  • 如果单元格只剩一个候选数，左键单击单元格内的空白处即可填入此数。
  • 启用筛选器后，如果筛选出的候选数构成隐性单值（Hidden Single），左键单击对应单元格的空白处即可填入此数。
  • 右键单击候选数可将其排除；右键单击单元格内的空白处，可重新启用对应候选数。
使用鼠标（着色模式）
单击状态栏或“当前单元格”视图中的颜色，可启用着色（Coloring）模式。单击单元格或候选数，可切换所选颜色。按 [X] 可交换主色与辅助色。单击背景色或按 [Esc] 可退出着色模式且保留染色；单击标有“R”的色块会清除全部染色。
[Shift][Option][R][1] ... [9]、[Shift][Option][C][1] ... [9]、[Shift][Option][B][1] ... [9]（macOS）
按住时分别临时高亮对应的行（Row）、列（Column）或九宫格（Block）；松开数字键、字母键、Shift 或 Option 后立即取消。主数字区和数字小键盘都可以使用。

移动光标，也就是当前高亮的单元格。
[Shift][左方向键]、[Shift][上方向键]、[Shift][右方向键]、[Shift][下方向键]
扩大所选单元格区域。
[Shift][Ctrl][左方向键]、[Shift][Ctrl][上方向键]、[Shift][Ctrl][右方向键]、[Shift][Ctrl][下方向键]
启用筛选器后，将光标移到下一个包含筛选候选数的未解单元格。
[Ctrl][左方向键]、[Ctrl][上方向键]、[Ctrl][右方向键]、[Ctrl][下方向键]
将光标移到下一个未解单元格。
[Home]
将光标移到最左列。
[End]
将光标移到最右列。
[Ctrl][Home]
将光标移到最上行。
[Ctrl][End]
将光标移到最下行。
[1] ... [9]
在当前单元格中填入数值；题目给定数（Given，显示为黑色）不能被覆盖。
[Ctrl][1] ... [Ctrl][9]
切换当前单元格中的对应候选数。
[空格]
设置筛选器后，可切换筛选出的候选数。
[Delete]、[Backspace]、[0]
删除单元格中的数值；题目给定数不能删除。没有当前选中单元格时，数字、删除和 Enter 不会修改题目；第一次按方向键只恢复上次导航锚点。

筛选器（Filters）

筛选器有两种显示方式：显示某个数字所有允许填入的单元格（绿色），或显示该数字所有禁止填入的单元格（红色）。

[F1] ... [F9]
设置或取消对应的筛选数字。
[Shift][F1] ... [Shift][F9]
设置或取消对应的筛选数字，同时切换筛选模式（允许/禁止）。
[Ctrl][F1] ... [Ctrl][F9]
向筛选候选数集合中添加候选数，或从中移除候选数。筛选多个候选数时，可以显示包含至少一个所选候选数的全部单元格（“或”，OR），也可以只显示同时包含全部所选候选数的单元格（“与”，AND）。
[Alt][1] ... [Alt][9]（macOS）
作为 [F1] ... [F9] 的替代操作；主数字区和数字小键盘都可以使用。
[Alt][Ctrl][1] ... [Alt][Ctrl][9]（macOS）
作为 [Ctrl][F1] ... [Ctrl][F9] 的多选替代操作。如果启用了 macOS 辅助功能中的键盘缩放快捷键，系统可能会优先截获 [Alt][Ctrl][8]。
[F10]
高亮所有仅剩两个逻辑候选数的未解单元格（XY）。
[Shift][F10]
高亮所有仅剩三个逻辑候选数的未解单元格（XYZ）。XY 与 XYZ 筛选相互独立，可以同时使用。
[Alt][0] / [Shift][Alt][0]（macOS）
分别作为 [F10] / [Shift][F10] 的 XY / XYZ 替代操作；主数字区和数字小键盘都可以使用。
[空格]
筛选器启用且当前单元格符合筛选条件时，切换单元格中的筛选候选数。
[Enter]
筛选器启用且当前单元格符合筛选条件时，将筛选候选数填入该单元格。
[>]、[.]
筛选器启用时，切换到下一个数字。
[<]、[,]
筛选器启用时，切换到上一个数字。

标注工具（Annotations）

染色：单击格／双击候选
左键设主色，右键清对应颜色；Shift＋左单击直接处理候选，Control＋左键并行删除。右拖按轨迹擦除格色与候选色，虚线圆表示范围，滚轮调整大小；右双击第二下拖框按格中心与候选中心混合清色，一次框擦一次撤销；侧栏可选仅格色／仅候选色。棋盘外画布留白右单击按时间清最近仍存在的染色，格与候选混排，快速连点逐项清除；格内未命中不删除远处内容。重染更新顺序，重复同色不更新；撤销／重做恢复原时间顺序。仅有双击动作的目标需要判定：从第一次按下起最多 200 毫秒（系统更短时沿用更短值）；其他位置松手即执行。同一候选内允许轻微移动，拖动取消单击。
[M] / [T] / [P] / [L] / [S]
切换到默认鼠标、上次使用的染色、涂鸦、自由链或框选工具。短按会固定工具；双击判定窗口结束后，再短按当前的 P、L 或 S 会恢复进入它之前的工具。T 进入或退出统一染色工具；左键单击染格、双击染候选；右键清除，Option／中键按住预览。按住可临时使用、松开后恢复；双击 T、P、L 或 S 会清空对应标注层，但不改变当前工具。
[a]/[A]、[b]/[B]、[c]/[C]、[d]/[D]、[e]/[E]
统一染色模式下，单按 A／B／C／D 选择前四组配色，不直接染色。Shift 配合字母及 E 保留原有选中格染色操作。
配色区滚轮 / [X]
滚轮整组切换颜色，X 或交换按钮交换主副色。Option／中键专用于按住预览，预览期间滚轮不换色。Command＋滚轮调整涂鸦笔宽，Control＋滚轮调整橡皮大小；滚轮保留原有节流。
涂鸦模式：[A]、[B]、[C]、[D]
选择前四组深浅配色，保留 X 交换后的顺序；配合 [Shift] 将浅色设为主色，深色仍为同组副色。
涂鸦模式：[>] / [<]
增大／减小笔触粗细。
涂鸦：左键单击／双击候选
左键单击添加真圈，双击添加假叉；Shift＋左单击直接添加叉。再次单击已有圈取消圈，再次双击已有叉取消叉；数字／Shift＋数字沿用切换圈／叉。圈叉可以共存；拖动画笔不先落圈，标准标记仍随候选缩放并整枚擦除。单击松手立即切换圈；200 ms 内第二击先恢复本次单击前状态再切换叉，不额外留圈或撤销记录。叉比圈更小；当前色组的叉和对应候选保持约 45% 不透明度。
涂鸦模式：Command＋左键
为当前色组的标准圈或叉切换亮蓝色窄边，描边紧贴这枚圈／叉图案的外轮廓；圆圈只描外沿，不画单元格框。它表示准备应用该结论。同一格最多一个外框；被框格在本组内不能再加其他候选标记。真圈外框与本组同行、同列或同宫的相同数字真圈冲突时不接受；假叉可跨格指定。同一候选在当前色组同时有圈和叉时，Command 单击选择／取消圈，Command 双击选择／取消叉；外框互斥，切换不删除圈叉。切换色组会隐藏其他组外框，切回后恢复；其他组的圈叉编辑不受影响。
涂鸦模式：按住 Option／中键预览当前色组（Space 兼容）
立即预览当前色组的全部标准标记，无需指向圈：圈显示为当前色组深色的填入数字；有效叉及其对应候选一起隐藏；同组矛盾显示醒目红色，其他组标记淡化。此预览只改显示，不改数独、不传播其他候选变化；F1/F2 仍读取真实盘面。最后一个预览按键松开、失焦或切换工具后恢复。
涂鸦模式：[Enter]
一次应用当前色组所有带外框的有效结论：圈填数、叉删候选。一次棋盘撤销、一次 Q 最近改盘回看、同一次赛事回放中的应用前批注证据和应用后盘面。成功后清除当前组全部涂鸦及外框，其他组记录和独立染色保留；无有效变化时不清除、不新增记录。Forward Delete 和 0 不执行此操作。涂鸦模式 Command＋Z 只撤销批注清理；切回 M／默认鼠标后 Command＋Z 撤销盘面。M／默认鼠标切入批注工具时，会清除绑定候选已不存在的圈叉、候选染色和链节点及相关连线。
自由链模式：单击 / [Space]
单击可见候选数添加不透明节点。第一条边默认为强链，之后强弱交替；Space 可切换下一条边。工具栏画链图标保留 L 提示，以“＝”表示下一条强链、“－”表示下一条弱链；已选中画链时再次点击图标也可切换，尚未落下第一个节点时也可预选。强链使用当前颜色组的深色，弱链使用对应浅色。
自由链模式：[Shift]＋单击
将候选加入最后一个节点，可包含不同数字、跨单位和超过三个成员。组真表示至少一个成员为真。普通点击选择候选所属整组；Command+点击仅选择该候选，不拆组；属于多个组时弹出选择条，悬停预览完整成员。等宽半透明带表示同组；松开 Shift 继续连接下一节点。点击首组任一成员可闭环。回车时无效连接标红，保留强弱线型；修改后重新验证。
自由链／框选模式：[A] / [B] / [C] / [D] 或滚轮
选择颜色组；共享调色盘仍可选择全部六组。这两个工具各自记忆颜色组，不使用副色控件。
框选：左键添加／右键删除
左单击或左拖将命中格加入当前组，重复添加不删除，其他组保留。右单击或右拖删除命中格的全部框色，Control＋左键同义。拖框按格中心命中；按住 Option／中键在底栏查看当前色组计数，松开恢复。Shift＋R 清全部框色组，不提供仅清当前组。
涂鸦：Shift＋左拖／左双击第二下按住拖动椭圆
沿用原空心椭圆绘制能力，以起点、终点构成外接矩形，保留当前画笔颜色和粗细。
涂鸦：右拖框擦／自由橡皮擦
右键直接拖动沿轨迹擦除，此时显示虚线圆形范围，滚轮调整大小；右键双击后按住第二下拖动（或 Control＋左拖）矩形擦除。框外笔画保留，一次手势一次撤销；Esc 取消未提交手势。
自由链：鼠标编辑与预览
右单击棋盘／画布任意位置退上一连接（包括候选处）；已完成段退回后恢复续画，下一次左键从剩余链尾连接；闭环第一次右键只断环，不删节点。右拖沿用节点／成员高亮与边一起删除。左拖翻转命中边。左单击棋盘外留白切下一条强弱，左双击留白切上一条强弱。左双击候选 A 再左单击 B 精确翻边；右双击 A 再右单击 B 精确删边，Control＋左键为删除并行入口。唯一匹配才修改；精确或拖动删除末条关联边时，相应 L 高亮一起清除，不影响数独候选。单双击与拖动互斥。Shift＋左单击留白或“结束段”按钮结束当前段；Shift＋左双击候选另起段。Option／中键按住邻接预览（H 不再响应；绿实线表示可强续链，橙虚线表示仅可弱续链）：允许按原关系检查续画，仅弱关系不能画成强边。最后一个预览来源松开、Esc、失焦或换工具退出。原组链、重叠选择、Command 单候选、首尾／闭环提示和 Enter 分析应用保持。
自由链／框选模式：[Enter]
第一次回车分析框选，或将当前全部链段作为一个整体验证；不区分已完成或未完成，不会只挑最后一段。用户应删除多余链段，使它们形成一条链或环；断开、分叉或强弱冲突会提示处理，连续环和不连续环按对应规则验证。有完整结论时显示预览，再次回车才重新校验并应用。框选只匹配到部分步骤时打开相关列表。成功应用仅清除本次使用的框选或链，取消和失败保留来源；Delete 不会执行预览。
[Ctrl][Z] / [Ctrl][Y]
处于任一标注工具时，只撤销／重做当前标注类型，不修改数独填数或候选数。
[r]
清除染色、涂鸦、用户链条和框选区域；可立即按 [Ctrl][Z] 恢复对应标注。
[Shift][R]
只清除当前工具对应的标注。
[Esc]
取消最近改变的临时层：未完成手势、分析／步骤预览、标注工具，或合并的候选筛选与普通单元格选区。再次调整某层会让它成为最新层；筛选与普通选区会在同一次 Esc 全部清空，不留下选中格。已完成的框选、链和涂鸦保留。按住 Shift、Control、Option 或 Command 不改变规则。技巧列表中 Enter 或明确点击实例才提交，Esc 或点外部关闭则取消浏览。

统一标注操作

棋盘焦点：[Tab] / [Shift][F12]
Tab 仅查看当前思路：已有框选、画链或手动染色时关联这些标注，不再受当前数字限制；没有这些标注时，才按当前数字、XY 筛选或选中格查找。Shift+F12 查看全盘步骤，可用菜单内单选按钮筛选，每次打开恢复全部。输入框和对话框中的 Tab 保留焦点导航。
染色：轨迹擦除／框选删除
右拖沿轨迹清色；右双击第二下拖动或 Control＋左拖框删。沿用格/候选中心命中，一次手势一次撤销。
框选：右键删除／按住预览计数
右键点按或拖框删除命中格的全部框色。按住 Option／中键在底栏查看当前组的未填格数和候选数字种数，松开恢复。
涂鸦：圈叉与擦除
左单击候选画圈，左双击或 Shift＋左单击画叉。右拖轨迹擦除，右双击第二下拖动框删。Option／中键按住预览当前组。
画链：Control 框删组成员
候选中心在框内则移出组，同时删除命中的链边；仅穿组带无动作。剩一成员退为普通节点。错误链边使用加粗红色并保留实虚线。

步骤显示会把此前的标注统一淡化，之后新增或修改的标注保持清晰；显示另一个步骤时重新划分，淡化不会叠加，重复 F12 显示同一步骤不重置分界。手画链预览依赖来源链：修改节点、组成员、已有边的强弱、删除、撤销／重做或清空链会退出预览。仅切换下一条强弱、配色或涂鸦研究不退出。Enter 原本验证全部手画链，新增链段也会使该来源改变。其他步骤继续保留独立快照；盘面数值或候选改变仍会使步骤失效。

工具栏配色与鼠标

六组配色紧密排列。M 模式下配色区淡化并停用；画链状态位显示 = / -，涂鸦状态位平时显示笔宽，按住右键擦除时显示橡皮直径并随滚轮更新。上方橡皮擦只清当前工具（Shift+R），下方 all 橡皮擦清全部标注（R），均不修改题目数值或候选。普通鼠标不再带颜色角标；删除修饰键的橡皮擦光标保留。

涂鸦模式左键单击候选数生成的完整圆圈会跟随该数字，窗口缩放和侧栏变化不会使它偏移。擦去部分后，剩余弧线恢复为普通涂鸦；撤销可恢复完整圈的定位。已有旧圈及 Shift＋左拖或左键双击第二下按住拖动的椭圆保持原缩放方式。

T/P/L 普通单击立即生效；200ms 内第二击先撤回本次单击，再执行双击或双击拖动。S 沿用直接增删。重叠链组需弹出成员选择器时，仍先区分单双击，避免弹窗遮挡第二击。

涂鸦起点与多色圈叉

P 模式下首个标准候选圈叉自动标为绿色起点；G 或“追加起点”切换录入，再按一次或 Esc 结束。换色、换工具或窗口失焦也结束录入。取消本色起点保留圈叉，不自动递补。同色多个起点必须同向：多圈表示至少一个真，多叉表示全体假；追加异向起点提示音且不响应。多圈不会作为每个成员都真预览或应用。追加／取消起点图标位于原模式功能框内；起点绿色贴边轮廓只表示额外状态，原圈叉保留画笔粗细。

同候选同类型的当前批注按来源颜色实时合成为多色圈叉；删除某色就立即退去该色，不读历史。是否满足完备互斥和可接纳由用户判断。Command 选择、Enter 应用；多色来源变化会取消该结论的待应用选择。S 保持原有功能。

P 色组聚焦与冲突

其他色组的批注淡化显示；同候选、同类型的多个来源以清晰的多色圈叉显示。候选数字只受当前色组的单色叉淡化，换组后恢复；共享叉不淡化候选。按住预览时冲突保留原圈／叉形状，以专用鲜红色显示，松开恢复原来源色。Command 蓝框结论使用回车应用，Backspace 不再应用。
