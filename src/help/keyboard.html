Normal Operation

Using the mouse (normal operation)
Clicking a cell selects that cell. Pressing [ctrl] or [shift] while clicking selects a region of cells. Setting cells/candidates:
  • Double click on a candidate sets it in the cell
  • If a cell has only one candidate left, double click on the cell sets that candidate in the cell
  • If filters are applied, double click on a filtered cell sets the filtered candidate in the cell, if it is a Hidden Single
  • Double click on a candidate while pressing [ctrl] toggles the candidate
Using the mouse (alternate mouse mode)
Region select as described above. Setting cells/candidates:
  • Left click a candidate sets it in the cell
  • If a cell has only one candidate left, left click on empty space in the cell sets that candidate in the cell
  • If filters are applied, left click on empty space in a filtered cell sets the filtered candidate in the cell, if it is a Hidden Single
  • Right click on a candidate eliminates the candidate, right click on empty space in a cell enables the corresponding candidate
Using the mouse (coloring mode)
Clicking a color in the status bar or the Active Cell view activates coloring mode. Clicking a cell/candidate toggles the selected color for that cell/candidate. Pressing [X] swaps the primary color with the secondary color. Clicking the background color or pressing [esc] ends coloring mode without deleting colors. Clicking the panel with the "R" deletes all colors.
[shift][option][R][1] ... [9], [shift][option][C][1] ... [9], [shift][option][B][1] ... [9] (macOS)
While held, temporarily highlights the corresponding row, column, or block. Releasing the digit, letter, Shift, or Option key clears the highlight immediately. Both the number row and numeric keypad are supported.
[left], [up], [right], [down]
Moves the cursor (the highlighted cell).
[shift][left], [shift][up], [shift][right], [shift][down]
Expands the range of selected cells.
[shift][ctrl][left], [shift][ctrl][up], [shift][ctrl][right], [shift][ctrl][down]
If filters are applied, the cursor is moved to the next unsolved cell, that contains the filtered candidate.
[ctrl][left], [ctrl][up], [ctrl][right], [ctrl][down]
Moves the cursor to the next unsolved cell.
[home]
Moves the cursor to the leftmost column.
[end]
Moves the cursor to the rightmost column.
[ctrl][home]
Moves the cursor to the topmost row.
[ctrl][end]
Moves the cursor to the bottommost row.
[1] ... [9]
Sets the value in the highlighted cell; givens (shown in black) cannot be overridden.
[Ctrl][1] ... [Ctrl][9]
Toggles the candidate in the highlighted cell.
[blank]
If a filter is set (see below) toggles the filtered candidate.
[del], [backspace], [0]
Deletes value in cell (givens cannot be deleted). With no active cell selection, number, delete and Enter keys leave the puzzle unchanged; the first arrow key restores the last navigation anchor.

Filters

Filters come in two varieties: Show all allowed cells for placing a certain digit (cells are green) or show all forbidden cells for a digit (cells are red).

[F1] ... [F9]
Sets/toggles the filtered digit.
[shift][F1] ... [shift][F9]
Sets/toggles the filtered digit and switches the filter mode (allowed/forbidden).
[ctrl][F1] ... [ctrl][F9]
Adds/removes the candidate to/from the set of filtered candidates. If more than one candidate is selected for filtering, either all cells are shown, that contain at least one filtered candidate ('OR'), or only cells are shown, that contain all filtered candidates ('AND').
[alt][1] ... [alt][9] (macOS)
Alternative to [F1] ... [F9], using either the number row or numeric keypad.
[alt][ctrl][1] ... [alt][ctrl][9] (macOS)
Alternative to [ctrl][F1] ... [ctrl][F9] for multi-filter selection. If the macOS Accessibility Zoom shortcut is enabled, the system may intercept [alt][ctrl][8].
[F10]
Highlights unsolved cells with exactly two logical candidates (XY).
[shift][F10]
Highlights unsolved cells with exactly three logical candidates (XYZ). XY and XYZ filters are independent and may be used together.
[alt][0] / [shift][alt][0] (macOS)
Alternatives to [F10] / [shift][F10] for XY / XYZ, using either the number row or numeric keypad.
[space]
If a filter is active and the current cell is filtered, toggle the filtered candidate in the cell.
[enter]
If a filter is active and the current cell is filtered, set the filtered candidate in the cell.
[>], [.]
If a filter is active, set the next digit.
[<], [,]
If a filter is active, set the previous digit.

Annotation tools

Coloring: click cell / double-click candidate
Left sets primary color; right removes the corresponding color. Shift+left targets a candidate directly; Control+left is the delete alias. Right drag sweeps cell and candidate coloring; its dashed circle shows the wheel-adjustable radius. Double-right second-press rectangles erase both hit cell and candidate colors in one undo transaction; the sidebar also offers cell-only/candidate-only erasure. Right-click outside-board canvas removes the most recently colored existing object, mixing cell/candidate chronology across colors. Rapid clicks remove successive objects. A local miss never removes remote coloring. Recoloring updates order; identical additions do not. Undo/redo restores order. Only targets with a distinct double action wait, for at most 200 ms from the first press (or the shorter system interval). Other singles run on release. Small motion within the same candidate still counts as a double; dragging cancels a pending click.

Windows Ctrl / Alt / Win correspond to macOS Command / Option / Control. Control is not a Command alias on macOS.

[M] / [T] / [P] / [L] / [S]
Switch to Default Mouse, the last Coloring tool, Doodle, Free Chain, or Box Selection. A short tap keeps the tool active; after the double-tap window closes, tap the active P, L, or S again to restore its preceding tool. T enters or leaves unified Coloring (left click: cell, double-click: candidate; right: erase). Hold a key to use its tool temporarily. Double-tap T, P, L, or S to clear that tool's annotation layer without changing the current tool.
[a]/[A], [b]/[B], [c]/[C], [d]/[D], [e]/[E]
In unified Coloring, unmodified A/B/C/D select the first four paired groups without painting. Shift-letter and E retain their existing selected-cell coloring behavior.
Palette wheel / [X]
Wheel changes paired colors; X or the swap button swaps primary and secondary. Option and middle mouse are held preview inputs; wheel changes are frozen during preview. Command+wheel changes Doodle width; Control+wheel changes eraser size. Existing wheel throttling is retained.
Doodle: [A] / [B] / [C] / [D]
Select one of the first four paired groups, preserving the X swap orientation; Shift selects the light primary and its same-group dark secondary.
Doodle: [>] / [<]
Increase or decrease stroke width.
Doodle: left click / double-click candidate
Left click adds a true circle; double-click or Shift+left click adds a false cross. Click an existing circle again to remove it; double-click an existing cross to remove it; number and Shift+number retain mark toggling. Circles and crosses can coexist. Dragging draws without first adding a circle. Candidate marks retain anchoring and whole-mark erasure.
Doodle: Command + left click
Toggle a narrow bright-blue contour that hugs the standard circle or cross glyph in the current color group to designate it for application. The contour follows that mark alone; a circle is traced along its outside edge, and no cell frame is drawn. A cell can have one outlined mark in that group; while it is outlined, that group cannot add another candidate mark in the cell. A true-circle outline is blocked by another outlined true circle for the same digit in a peer row, column or box; false crosses may be outlined across cells. If both coexist on the same candidate in the current group, Command single-click toggles the circle outline and Command double-click toggles the cross outline. Switching polarity removes the opposite outline but keeps both marks. Switching groups hides the other group's outlines and restores them when you return; marks in other groups remain independent.
Doodle: hold Option / middle mouse (Space also supported)
Immediately preview every standard mark in the current color group without hovering a circle: circles appear as filled values in the current group's dark color; valid crosses and their candidates disappear. Contradictions in the group turn bright red; other groups fade. This changes the display only: it does not mutate Sudoku or propagate peer-candidate changes, and F1/F2 still use the real board. Releasing the last preview input, losing focus or changing tools restores the board.
Doodle: [Enter]
Apply the current color group's valid outlined conclusions in one action: circles fill values and crosses delete candidates. The board records one undo; Q reviews the board change; replay stores the annotation evidence and resulting board in the same operation. A successful apply clears all Doodle marks and freehand strokes in the current group, while other groups and independent coloring remain. No effective change means no clearing or new record. Forward Delete and 0 do not apply conclusions. Command+Z in Doodle undoes only annotations; switch to M / Default Mouse and use Command+Z to undo the board. Entering any annotation tool from M / Default Mouse clears candidate-bound marks, candidate coloring and chain nodes/edges whose candidates no longer exist.
Free Chain: click / [space]
Click visible candidates to add opaque nodes. The first relation is Strong; subsequent relations alternate Strong/Weak, and Space changes the next relation. Strong uses the selected pair's deep color and Weak its light color.
Free Chain: [Shift] + click
Extend the last node with any existing candidate, including mixed digits, different houses and more than three members. A true group means at least one member is true. Click selects its whole group; Command-click selects the single candidate without splitting it. Overlapping groups offer a chooser with full-member hover previews. A translucent band as wide as the candidate disks joins members. Release Shift to continue to the next node; click any first-group member to close. Enter marks invalid links red while retaining strong/weak line styles. Edit and validate again.
Free Chain conclusion preview: [Shift][Enter]
Prepare all atomic chain conclusions for transcription and switch to Doodle. Choose its color group and set one or more hypothesis starts, then press Enter again. This preserves the starts, replaces the group's other marks and free ink with ordinary conclusion circles/crosses, and consumes the source chain without changing the real board. You confirm that the starts justify every extra assumed relation; the tool does not certify that claim. Conflicting results remain as refutation evidence. Leaving P, switching applications or changing the source board/chain cancels preparation while retaining your ink and unconsumed chain. Escape first ends start entry or a local interaction, then cancels preparation. P undo restores the pre-transfer ink; L undo separately restores the consumed chain. Neither undo nor reopening restores preparation. Holding Enter cannot confirm twice or apply a subsequent P result.
Free Chain / Box Selection: [A] / [B] / [C] / [D] or wheel
Select a color group. All six groups remain available from the shared palette; these tools store their own group and do not use the Secondary control.
Box Selection: left adds / right removes
Left click or drag adds cells to the current group, preserving other groups. Repeated addition is idempotent. Right click/drag or Control+left removes all box colors on hit cells. Rectangles hit cell centers. Hold Option/middle mouse to inspect current-group counts in the status bar; release to exit. Shift+R clears all Box groups. While A-D is held, erasure and clearing affect only that color group in the current tool.
Doodle: Shift + left drag / double-left second-press drag
Draw an outline ellipse with the current width and color, using the endpoints as its bounding rectangle. The second press may start elsewhere; only starting the drag replaces the first click. Clicking a different candidate without dragging keeps both single clicks.
Doodle: right rectangle / Free eraser
Right drag erases along the pointer path, with a dashed radius circle and wheel size adjustment. Double-right-click, holding the second press while dragging, or Control+left drag erases a rectangle. The second press may start elsewhere; starting its drag replaces the first click. Outside fragments survive; each gesture is one undo transaction. Escape cancels an unfinished gesture.
Free Chain: mouse edits and held preview
Right click anywhere on the board/canvas retreats the last connection, including on a candidate. A completed segment reopens at its remaining tail so the next left click continues it; a closed loop first opens without removing a node. Right drag deletes hit edges and node/member highlights together. Left drag flips hit edges. Left click outside-board canvas toggles next strength. Ordinary double-left anywhere on the board/canvas flips the last connection; double-right retreats once with one undo. Only double-clicking the same already connected candidate A enters precise editing; then click B with the same button to flip (left) or delete (right) their unique edge. Middle-chain nodes and group members are eligible; isolated starts are not. Different L candidates clicked within the double-click window also trigger the global action. Control+left retains its delete alias. Precise or drag deletion of the last edge also removes affected orphan highlights without deleting Sudoku candidates. Single/double/drag actions are exclusive. Shift+left canvas or Finish segment ends a segment; Shift+double-left candidate starts another. Hold Option/middle mouse for relation preview; H no longer activates it. Green solid rings allow strong continuation; orange dashed rings allow weak continuation only. Relation-checked drawing still works during preview. Weak-only targets cannot receive a strong edge. The last release, Escape, focus loss or tool change exits preview. Existing groups, overlap chooser, Command singleton, endpoint cues and Enter analysis/application remain.
Free Chain / Box Selection: [enter]
First Enter analyzes the boxes or validates all authored segments as one connected chain or loop, never just the latest segment. Remove extras; disconnected, branched or conflicting input is reported. Continuous and discontinuous loops use their respective rules. A complete conclusion is previewed. Partial Box matches open the related-step browser. Enter again revalidates and applies that step, then removes only the Box regions or user chain used by the successful analysis. A preview or failed Apply keeps its source. Delete never applies a reasoning preview.
[ctrl][z] / [ctrl][y]
While an annotation tool is active, undo or redo only that annotation type without changing Sudoku contents.
[r]
Clear coloring, doodles, user chains, and Box regions; the corresponding annotation clear can be undone.
[shift][r]
Clear only the current annotation type.
[esc]
Cancel an analysis/preview or unfinished gesture, then return to Default Mouse; from Default Mouse it continues through the layered hint/filter reset behavior. The same priority applies while a modifier key is still held.

Held color-group erasure

Press A/B/C/D to select the current tool's color group immediately. Hold the key while using right-click erasure, sweep or rectangle deletion, Control deletion, R/Shift+R or toolbar clearing to affect only that group, including both shades, in T/P/L/S. Doodle A never erases Free Chain A. A pointer gesture keeps its original scope through mouse release, even if the key is released first. Subsequent gestures return to ordinary erasure. Key repeats do not switch palettes or interrupt double-clicks. Tool changes and focus loss end the hold; fields, dialogs and read-only replay retain their input boundaries.

Unified annotations

Board Tab / Shift+F12
Tab searches existing boxes, chains or manual coloring regardless of the digit filter. Only without those annotations does it use the digit, XY filter or selection. Shift+F12 opens all steps with in-menu radio filters, resetting to All steps each time. Tab keeps normal focus navigation in fields and dialogs.
Coloring (T)
Left-click colors a cell; double-left colors a candidate. Right drag sweeps; double-right second-press drag or Control-left drag erases a rectangle. One gesture, one undo.
Box right click
Right click/drag deletes box colors. Use Hold Option/middle mouse for current-group counts in the status bar.
Doodle candidate marks
Left-click circles; double-left or Shift-left crosses. A single click acts immediately; a second click within 200 ms restores the pre-click state before applying its double-click action. Crosses are smaller and only candidate digits under the current group's single-source crosses use 45% opacity; cross bodies retain their source color. Hold Option/middle for current-group preview anywhere. Right drag sweeps; double-right second-press drag erases a rectangle. Command outlines and Enter application remain available.
Chain rectangle deletion
Remove grouped members whose centers are inside, as well as intersected edges. A band-only hit does nothing. Invalid links are thicker red lines with their original strong/weak style.

Showing a proof fades earlier annotations once. Later annotations remain clear above it. A different proof starts a new boundary; repeating F12 for the same proof preserves it. Closing the proof restores annotations. Editing the source of a manual-chain preview, undoing/redoing chains or clearing them closes that preview. Next-edge strength settings, recoloring and unrelated visual research do not. Enter checks all submitted manual chains, so adding a segment changes that source. Other displayed proofs retain their snapshot behavior; changing Sudoku values or candidates invalidates them.

Escape cancels the most recently changed temporary layer: a pending gesture, analysis or step preview, annotation tool, or the combined candidate-filter and ordinary-cell-selection layer. Adjusting a layer makes it newest again. One Escape clears every candidate filter and the entire ordinary selection together; completed boxes, chains, and doodles remain. Modifier keys do not change this rule. In the technique list, Enter or an explicit instance click commits; Escape or closing the list cancels browsing.

Palette toolbar and pointer

The six paired swatches share a compact surface. Palette controls dim and disable in M mode. The state slot shows = / - for chains or brush width for Doodle, switching to wheel-adjustable eraser diameter while the right button is held. The upper eraser clears the current tool (Shift+R); the lower all eraser clears all annotations (R), preserving puzzle values and candidates. The regular pointer has no color badge; deletion-modifier eraser cursors remain.

New Doodle left-click candidate circles follow their cell and digit across window resizing and sidebar changes. Partial erasure detaches the remaining arcs into ordinary ink; undo restores the complete anchored circle. Legacy circles and Shift-left-drag ellipses keep their existing scaling.

Doodle assumptions and multi-color marks

In P, the first standard candidate mark becomes a green starting premise. Tap G to toggle entry; hold G for temporary entry and release to end it. Double-tap G cancels current-color start identities while preserving the marks. Clicking Append premise still toggles entry. Escape, color/tool changes or window deactivation ends entry. Cancel starts preserves ink and does not promote another mark. Starts within one color must have the same polarity: multiple circles mean at least one true, and multiple crosses mean all false. An opposite-polarity addition beeps and makes no change. Start icons occupy the existing mode-control group; green close-fitting contours mark start state without changing the circle/cross brush width. An OR group is never previewed or applied as individually true members.

Current marks for the same candidate and polarity compose using their actual source colors. Removing a source immediately removes that color; history does not contribute. The user judges exhaustive mutually exclusive assumptions when accepting a result. Command selects, Enter applies; changed compound sources cancel that pending selection. S keeps its existing behavior.

P palette focus and conflicts

M/T/P/L/S retain full source colors in normal display, without additional fading by tool or color group. Native proof annotation timing layers apply separately. Multiple sources marking the same candidate and polarity remain a clear multi-color circle/cross. Candidate dimming follows only the current group's single-source cross and clears on a group change; shared crosses do not dim the candidate. Held-preview conflicts keep their original circle/cross geometry in dedicated bright red; release restores source colors. Enter applies Command-outlined conclusions; Backspace no longer applies them.

Evidence-based strong targets and complete groups

Hold Option or middle mouse in Free Chain to preview targets supplied by current all-false Doodle starts and their circled conclusions, complete digit groups of a same-color boxed ALS, or the complete remainder of declared true Doodle starts. Strong and weak relations are checked independently. A target incompatible with the next edge uses a pale red dash-dot outline and cannot be connected.

A normal click on any group member connects the complete group; overlapping groups require an explicit choice. Command-left-click selects a singleton only when that candidate has its own relation, without borrowing the group's qualification. Holding Command previews independent singletons; releasing it restores groups. Premises are checked during preview and at the final click or group choice. Connected edges retain ordinary authored-chain and Enter behavior without persistent Doodle or Box references.

All-cross Doodle starts implying a non-start circle supply a strong relation. All-circle starts implying a non-start cross supply a weak relation. Circled starts mean at least one member is true. The current complete tail must exactly match all same-color starts, whether single or grouped; one member cannot borrow the group's implication. Strong and weak qualifications remain independent and current marks are checked at the final click.

Smaller circle starts from color groups

Record starts and circle/cross conclusions in the existing color groups. When the current false starts exclude part of a declared at-least-one-true circle group, the P toolbar offers Use as circle starts with the member counts. Complete coverage by several branches and common true representatives also qualify. Click to adopt the smaller OR in the current color; choose explicitly when several complete results are available. Existing L complete-remainder links need no additional merge step.

The adopted circle starts remain visible. Hold Option or middle mouse to view the old starts and intermediate ink as readonly sources; release hides them. Sources do not affect candidate projection, Command selection or Enter application. Undo, redo and normal session persistence retain the state, and actual records in other colors remain available.

If X true excludes one part of the original OR and Y true excludes all remaining members, complete coverage supplies only a weak relation: X and Y cannot both be true. Hold the existing L preview, select a weak edge and connect normally. This does not create an at-least-one-true circle group or certify manually recorded implications.

Doodle contradictions and reversed starts

Necessary Sudoku conflicts recolor their original circle/cross witnesses red; shared marks keep the other source colors. Valid starts gain opposite marks with blue outlines while retaining their green start outlines. Other selections in that group are cleared. This also appears in held preview; original marks remain editable, and automatic results disappear when the conflict is removed. Command does not add selections while automatic results are present. Enter accepts the complete inverse: a circle deletes its candidate, a cross fills its digit, and a circle OR deletes every member. Multiple false starts become a new circle OR without changing the board. The old active group exits; other sources remain. OR adoption preserves its old deductions as readonly sources and supports one doodle undo.

Doodle deadly rectangles

For a validated unique puzzle, explicitly draw all four true circles in one group. If they form a diagonal two-digit pattern in exactly two rows, two columns and two boxes, deduction circles turn red in their original shape; starts retain green outlines and gain blue inverse selections. Boxes are not required. Missing circles, crosses, other groups and OR members do not complete this witness. Held preview helps inspect your marks. Enter accepts the inverse; editing or undoing the complete witness withdraws it.

Complete assumption branch

A single-start color branch that circles exactly one value for every empty cell and completes a legal Sudoku receives automatic blue conclusion outlines, including its single true start. Enter rechecks and fills the whole completion in one board action; one board undo restores it. Incomplete, conflicting, multiple-OR-start or other-color branches do not qualify. Automatic selection is display-only and is recomputed after normal session restore.

Editing existing start roles

During start entry, click for a circle or double-click / Shift-click for a cross. If that shape already exists, only its start role toggles; ink and its manual outline remain. Choosing the opposite shape replaces the current-color mark with a new start and gives clear feedback. A replacement that conflicts with other current-color starts is rejected without changing them.

After Enter accepts a manual or shared conclusion, valid current-color starts and their read-only sources remain; ordinary derivation ink and applied selections clear. Invalid starts clear. Filling a member satisfies its entire at-least-one-true condition; the remaining members do not become a new premise. Color/tool changes and ending entry preserve recorded starts.

Double-tap G cancels current-color start roles. Double-tapped mode keys, R and Shift+R clear annotations. Explicit clears and direction replacements share feedback controlled by Play operation sounds; empty clears stay silent. Mouse double-click rollback also discards provisional feedback, so only the final action sounds.
