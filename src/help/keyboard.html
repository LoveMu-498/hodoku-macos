Normal Operation

Using the mouse (normal operation)
Clicking a cell selects that cell. Pressing [ctrl] or [shift] while clicking selects a region of cells. Setting cells/candidates:
  • Double click on a candidate sets it in the cell
  • If a cell has only one candidate left, double click on the cell sets that candidate in the cell
  • If filters are applied, double click on a filtered cell sets the filtered candidate in the cell, if it is a Hidden Single
  • Double click on a candidate while pressing [ctrl] toggles the candidate
Using the mouse (alternate mouse mode)
Region select as described above. Setting cells/candidates:
  • Left click a candidate sets it in the cell
  • If a cell has only one candidate left, left click on empty space in the cell sets that candidate in the cell
  • If filters are applied, left click on empty space in a filtered cell sets the filtered candidate in the cell, if it is a Hidden Single
  • Right click on a candidate eliminates the candidate, right click on empty space in a cell enables the corresponding candidate
Using the mouse (coloring mode)
Clicking a color in the status bar or the Active Cell view activates coloring mode. Clicking a cell/candidate toggles the selected color for that cell/candidate. Pressing [X] swaps the primary color with the secondary color. Clicking the background color or pressing [esc] ends coloring mode without deleting colors. Clicking the panel with the "R" deletes all colors.
[shift][option][R][1] ... [9], [shift][option][C][1] ... [9], [shift][option][B][1] ... [9] (macOS)
While held, temporarily highlights the corresponding row, column, or block. Releasing the digit, letter, Shift, or Option key clears the highlight immediately. Both the number row and numeric keypad are supported.
[left], [up], [right], [down]
Moves the cursor (the highlighted cell).
[shift][left], [shift][up], [shift][right], [shift][down]
Expands the range of selected cells.
[shift][ctrl][left], [shift][ctrl][up], [shift][ctrl][right], [shift][ctrl][down]
If filters are applied, the cursor is moved to the next unsolved cell, that contains the filtered candidate.
[ctrl][left], [ctrl][up], [ctrl][right], [ctrl][down]
Moves the cursor to the next unsolved cell.
[home]
Moves the cursor to the leftmost column.
[end]
Moves the cursor to the rightmost column.
[ctrl][home]
Moves the cursor to the topmost row.
[ctrl][end]
Moves the cursor to the bottommost row.
[1] ... [9]
Sets the value in the highlighted cell; givens (shown in black) cannot be overridden.
[Ctrl][1] ... [Ctrl][9]
Toggles the candidate in the highlighted cell.
[blank]
If a filter is set (see below) toggles the filtered candidate.
[del], [backspace], [0]
Deletes value in cell (givens cannot be deleted). With no active cell selection, number, delete and Enter keys leave the puzzle unchanged; the first arrow key restores the last navigation anchor.

Filters

Filters come in two varieties: Show all allowed cells for placing a certain digit (cells are green) or show all forbidden cells for a digit (cells are red).

[F1] ... [F9]
Sets/toggles the filtered digit.
[shift][F1] ... [shift][F9]
Sets/toggles the filtered digit and switches the filter mode (allowed/forbidden).
[ctrl][F1] ... [ctrl][F9]
Adds/removes the candidate to/from the set of filtered candidates. If more than one candidate is selected for filtering, either all cells are shown, that contain at least one filtered candidate ('OR'), or only cells are shown, that contain all filtered candidates ('AND').
[alt][1] ... [alt][9] (macOS)
Alternative to [F1] ... [F9], using either the number row or numeric keypad.
[alt][ctrl][1] ... [alt][ctrl][9] (macOS)
Alternative to [ctrl][F1] ... [ctrl][F9] for multi-filter selection. If the macOS Accessibility Zoom shortcut is enabled, the system may intercept [alt][ctrl][8].
[F10]
Highlights unsolved cells with exactly two logical candidates (XY).
[shift][F10]
Highlights unsolved cells with exactly three logical candidates (XYZ). XY and XYZ filters are independent and may be used together.
[alt][0] / [shift][alt][0] (macOS)
Alternatives to [F10] / [shift][F10] for XY / XYZ, using either the number row or numeric keypad.
[space]
If a filter is active and the current cell is filtered, toggle the filtered candidate in the cell.
[enter]
If a filter is active and the current cell is filtered, set the filtered candidate in the cell.
[>], [.]
If a filter is active, set the next digit.
[<], [,]
If a filter is active, set the previous digit.

Annotation tools

Windows Ctrl / Alt / Win correspond to macOS Command / Option / Control. Control is not a Command alias on macOS.

[M] / [T] / [P] / [L] / [S]
Switch to Default Mouse, the last Coloring tool, Doodle, Free Chain, or Box Selection. A short tap keeps the tool active; after the double-tap window closes, tap the active P, L, or S again to restore its preceding tool. T enters or leaves unified Coloring (left: cell, right: candidate). Hold a key to use its tool temporarily. Double-tap T, P, L, or S to clear that tool's annotation layer without changing the current tool.
[a]/[A], [b]/[B], [c]/[C], [d]/[D], [e]/[E]
In unified Coloring, unmodified A/B/C/D select the first four paired groups without painting. Shift-letter and E retain their existing selected-cell coloring behavior.
Palette wheel / [X] / [Alt]
Wheel changes both colors as a pair, also with Alt (Option) held. X swaps their deep/light order; Option temporarily uses Secondary. The swap glyph shows Opt above and X below. Hiding the toolbar restores the sidebar palette. Chain and Box use Primary only; Doodle wheel also changes the color pair; Command+wheel adjusts width. Click the width icon to cycle four levels. A wheel gesture advances one step after accumulating a full notch; pause 350 ms before the next step.
Doodle: [A] / [B] / [C] / [D]
Select one of the first four paired groups, preserving the X swap orientation; Shift selects the light primary and its same-group dark secondary.
Doodle: [>] / [<]
Increase or decrease stroke width.
Free Chain: click / [space]
Click visible candidates to add opaque nodes. The first relation is Strong; subsequent relations alternate Strong/Weak, and Space changes the next relation. Strong uses the selected pair's deep color and Weak its light color.
Free Chain: [Shift] + click
Extend the last node into a group of two or three occurrences of the same digit in one row, column, or box. A translucent band as wide as the candidate disks joins members. Release Shift to continue to the next node; click any first-group member to close. Enter marks invalid links red while retaining strong/weak line styles. Edit and validate again.
Free Chain / Box Selection: [A] / [B] / [C] / [D] or wheel
Select a color group. All six groups remain available from the shared palette; these tools store their own group and do not use the Secondary control.
Box Selection: left click / left drag / Control + left drag
Toggle each hit cell: remove all box colors if selected, otherwise add the current group. Dragging hits cell centers. Control only removes and never adds. Counts are hidden until a right-click inspection.
Doodle: right drag
Draw an outline ellipse using the drag endpoints as its bounding rectangle, with the current brush width and color.
Doodle: [Win] + left/right drag
The deletion modifier displays a circular eraser; the wheel changes its range. Left drag cuts stroke portions along the path; right drag erases inside the rectangle on release. Outside fragments survive. Each gesture has one undo entry; Escape cancels the pending gesture.
Free Chain: right click / Control + left drag
Right click toggles the latest edge; right drag toggles every intersected edge. Editing the last edge updates the next strength; Space still toggles the next edge. Option + two right clicks selects exact endpoints to toggle; Option + Control + two left clicks deletes their edge. Any group member represents its whole node. Missing or ambiguous edges remain unchanged. Release the modifiers to cancel endpoint selection. Control + left drag retains batch deletion. Backspace or Control + right click retreats the active chain, or deletes the latest completed edge when no chain is active. Control + right drag does nothing. Shift + right click finishes a segment; Option + left click starts a new segment at that candidate. Subtle arc caps mark the start and end of the current or most recent multi-node segment, replacing its terminal arrow. A closed loop has both caps at its start. Edits are undoable. An unrendered technique selection does not intercept Box/Chain Enter. A displayed proof is frozen: Enter applies it; Esc closes it before Enter can analyze new annotations.
Free Chain / Box Selection: [enter]
First Enter analyzes the boxes or validates all authored segments as one connected chain or loop, never just the latest segment. Remove extras; disconnected, branched or conflicting input is reported. Continuous and discontinuous loops use their respective rules. A complete conclusion is previewed. Partial Box matches open the related-step browser. Enter again revalidates and applies that step, then removes only the Box regions or user chain used by the successful analysis. A preview or failed Apply keeps its source. Delete never applies a reasoning preview.
[ctrl][z] / [ctrl][y]
While an annotation tool is active, undo or redo only that annotation type without changing Sudoku contents.
[r]
Clear coloring, doodles, user chains, and Box regions; the corresponding annotation clear can be undone.
[shift][r]
Clear only the current annotation type.
[esc]
Cancel an analysis/preview or unfinished gesture, then return to Default Mouse; from Default Mouse it continues through the layered hint/filter reset behavior. The same priority applies while a modifier key is still held.

Unified annotations

Board Tab / Shift+F12
Tab searches existing boxes, chains or manual coloring regardless of the digit filter. Only without those annotations does it use the digit, XY filter or selection. Shift+F12 opens all steps with in-menu radio filters, resetting to All steps each time. Tab keeps normal focus navigation in fields and dialogs.
Coloring (T)
Left click colors a cell, right click a candidate. Both use primary color, or secondary with Option. Control-left rectangle erases cell colors by center; Control-right erases candidate colors by center. One gesture, one undo.
Box right click
Inspect the hit box group, or the current color group on a miss. An empty fallback does nothing. Show unsolved cell count and distinct candidate digits, excluding filled cells. Right click never changes boxes; Control-right does nothing. Editing boxes or changing color/tool dismisses counts.
Doodle right click
Click a visible candidate for a highlight-sized hollow circle. Right drag remains ellipse; Control-right remains eraser.
Chain rectangle deletion
Remove grouped members whose centers are inside, as well as intersected edges. A band-only hit does nothing. Invalid links are thicker red lines with their original strong/weak style.

Showing a proof fades earlier annotations once. Later annotations remain clear above it. A different proof starts a new boundary; repeating F12 for the same proof preserves it. Closing the proof restores annotations. Editing annotations preserves the displayed proof, but changing Sudoku values or candidates invalidates it.

Palette toolbar and pointer

The six paired swatches share a compact surface. Palette controls dim and disable in M mode. The state slot shows = / - for chains or brush width for Doodle. The upper eraser clears the current tool (Shift+R); the lower all eraser clears all annotations (R), preserving puzzle values and candidates. The regular pointer has no color badge; deletion-modifier eraser cursors remain.

New Doodle right-click candidate circles follow their cell and digit across window resizing and sidebar changes. Partial erasure detaches the remaining arcs into ordinary ink; undo restores the complete anchored circle. Legacy circles and right-drag ellipses keep their existing scaling.
